# 日语学习站 · あお老师 —— 上线说明（腾讯云开发 CloudBase）

这份说明写给不写代码的你，照着一步步做就能上线。
菜单名称是按 2026 年 10 月腾讯云官方文档写的，**控制台改版后名字可能略有不同，以控制台实际显示为准**。

---

## 先了解：网站有两种模式

| 模式 | 条件 | 能用的功能 |
| --- | --- | --- |
| 离线 / 演示模式 | `js/config.js` 里 `envId` 留空 | 假名练习、打卡等全部在本机浏览器保存；不能登录、没有排行榜、咨询表单只显示演示提示 |
| 在线模式 | 填好 `envId` 并完成下面的部署 | 邮箱验证码登录、进度云端同步、周排行榜、咨询表单（并发邮件通知你） |

不部署也能先把网站当纯静态页面放上去用（离线模式）。

## 文件说明

```
learn/
├─ index.html、kana.html、css/、js/   ← 网站本身（上传到"静态网站托管"）
├─ js/config.js                       ← 只需要改这里的 envId
├─ js/api.js                          ← 网页和云端之间的接口（不用改）
├─ cloudfunctions/                    ← 3 个云函数（部署到"云函数"，不要上传到网站托管）
│   ├─ progress/  学习进度同步 + 周排行榜
│   ├─ profile/   昵称、注销账号
│   └─ inquiry/   咨询表单 + 邮件通知
├─ cloudbaserc.json                   ← 部署云函数用的配置
├─ database-rules.md                  ← 数据库集合与安全规则
└─ README-上线说明.md                 ← 本文件
```

## 第 1 步：注册腾讯云并实名认证

1. 打开 <https://cloud.tencent.com>，用微信或 QQ 注册账号。
2. 进入「账号中心」完成**实名认证**。
   - 以后要做"个体户经营性 ICP 备案"，建议直接用**个体工商户（企业）认证**；如果先用个人实名，以后可以升级/变更，具体以腾讯云要求为准。

## 第 2 步：开通云开发环境，记下 envId

1. 打开云开发控制台：<https://tcb.cloud.tencent.com>（或在腾讯云控制台搜索"云开发 CloudBase"）。
2. 点「新建环境」，地域建议选 **上海**（和 `js/config.js` 里的 `region: "ap-shanghai"` 一致；如果选了别的地域，记得把 region 也改掉）。
3. 套餐：选择适合的套餐。**价格和免费额度经常调整，请以控制台下单页显示为准**，这里不写具体数字。
4. 创建好后，环境概览里会显示**环境 ID（envId）**，形如 `breeze-1a2b3c4d`。把它记下来。

## 第 3 步：开启登录方式（邮箱验证码 + 匿名登录）

进入：**云开发平台 → 身份认证 → 登录方式**（以控制台为准）

1. **邮箱验证码登录**
   - 找到「邮箱验证码」卡片，点「配置发件邮箱」。
   - 官方提供两种发件方式：
     - **开启邮件代发**（官方推荐，零配置，保存即生效）——最省事，建议先用这个。
     - 自定义 SMTP：也可以用 QQ 邮箱发验证码（服务器 `smtp.qq.com`，端口 `465`，SSL，用户名=QQ邮箱，密码=授权码；授权码获取方法见第 6 步）。
   - 开启后保存。
2. **匿名登录**
   - 在同一页面找到「匿名登录」，打开。
   - 为什么要开：没登录的访客提交"咨询表单"、查看排行榜时，网站会自动以匿名访客身份调用云函数。不开的话，未登录访客无法提交咨询。
   - 匿名访客**不能**保存学习进度或上排行榜（云函数里已限制）。

> 关于登录方式的说明：现行 CloudBase JS SDK v2 支持"邮箱 + 验证码"直接登录：
> 输入邮箱 → 收到 6 位验证码 → 输入后登录。**新邮箱会自动注册，老邮箱直接登录**，不需要设置密码。
> 代码使用 `auth.signInWithOtp({ email })` + `verifyOtp({ token })`，如 SDK 版本不支持则自动改用 `auth.getVerification` + `auth.signInWithEmail`。

## 第 4 步：安全域名（防止网页调用被拦截）

进入：**云开发平台 → 环境配置 → 安全来源 / 安全域名**（菜单名以控制台为准）

- 云开发自带的默认托管域名一般已自动加入。
- 以后绑定自己的域名（如 `breeze.example.com`）后，**一定要把新域名加进来**，否则网页里登录、排行榜会报错。
- 如果你在自己电脑上用 `http://localhost:xxxx` 测试，也需要临时加上。

## 第 5 步：安装 Node.js 与 CloudBase CLI

1. 安装 Node.js（LTS 版）：<https://nodejs.org> 下载安装包，一路"下一步"。
2. 打开"终端"（Mac）或"命令提示符 / PowerShell"（Windows），输入：

   ```bash
   node -v
   npm i -g @cloudbase/cli
   tcb -v
   ```
   能看到版本号就说明装好了。（Mac 如提示权限不足，在命令前加 `sudo `。）
3. 登录：

   ```bash
   tcb login
   ```
   会弹出浏览器，用腾讯云账号扫码/确认授权即可。

## 第 6 步：填写 envId

用记事本（或 VS Code）打开以下两个文件，把 `your-env-id` / 空字符串换成第 2 步记下的 envId：

1. `js/config.js`：

   ```js
   envId: "breeze-1a2b3c4d",
   ```
2. `cloudbaserc.json`：

   ```json
   "envId": "breeze-1a2b3c4d",
   ```

> envId 不是密码，可以公开。

## 第 7 步：部署云函数 + 设置环境变量

### 7.1 部署

在终端里进入 `learn` 文件夹（把下面路径换成你电脑上的实际位置）：

```bash
cd 你的路径/learn
tcb fn deploy --all
```

- 如果提示"函数已存在，是否覆盖"，选"是"；也可以加 `--force`。
- 依赖（`@cloudbase/node-sdk`、`nodemailer`）会在云端自动安装（配置里 `installDependency: true`）。
- 只想重新部署某一个函数时：`tcb fn deploy inquiry`。
- **注意**：新版 CLI 部署时如果询问环境变量是"增量更新"还是"覆盖"，请选**增量 / 保留线上配置**，否则可能清掉第 7.3 步填的邮箱配置。部署后最好回控制台确认一下环境变量还在。

### 7.2 在 QQ 邮箱生成"授权码"

授权码是专门给程序发邮件用的密码，**不是你的 QQ 密码**。

1. 网页登录 QQ 邮箱 <https://mail.qq.com>。
2. 点右上角「设置」→「账号」（新版界面可能是「设置 → 账号与安全」，以实际为准）。
3. 找到「POP3/IMAP/SMTP/Exchange/CardDAV 服务」，开启 **IMAP/SMTP 服务**（或 POP3/SMTP）。
4. 按提示用手机发短信验证，页面会显示一串**授权码**（16 位左右字母）。复制下来。

### 7.3 把邮箱信息填到云函数环境变量

进入：**云开发平台 → 云函数 → 点击 `inquiry` → 函数配置 → 编辑 → 环境变量**（以控制台为准），添加三项：

| 变量名 | 填什么 | 例子 |
| --- | --- | --- |
| `SMTP_USER` | 用来发通知的 QQ 邮箱 | `12345678@qq.com` |
| `SMTP_PASS` | 上一步拿到的**授权码** | `abcdefghijklmnop` |
| `NOTIFY_TO` | 你想收到咨询通知的邮箱（可以和上面相同） | `12345678@qq.com` |

保存即可。

> ⚠️ **授权码只填在腾讯云控制台这里，不要发给任何人**（包括客服、朋友、AI 助手），也不要写进网站任何文件。
> 万一泄露：回 QQ 邮箱把该授权码"停用"，重新生成一个，再更新这里的 `SMTP_PASS`。
>
> 没填这三项也没关系：咨询照样会保存到数据库（你在控制台能看到），只是不会发邮件提醒。

## 第 8 步：建数据库集合 + 设置安全规则

进入：**云开发平台 → 文档型数据库 → 集合管理**（以控制台为准）

1. 新建 4 个集合：`profiles`、`progress`、`inquiries`、`ratelimits`（名字必须完全一致，全小写）。
2. 每个集合：点「权限管理」→「切换到安全规则」→ 粘贴下面内容 → 保存：

   ```json
   { "read": false, "write": false }
   ```
   这表示网页不能直接碰数据库，一切都经过云函数，最安全。
3. （可选）按 `database-rules.md` 建索引。

详细说明见 `database-rules.md`。

## 第 9 步：上传网站（静态网站托管）

1. 控制台进入 **静态网站托管**，如果还没开通，先点「开通」。（命令行不会自动帮你开通。）
2. 两种上传方式，任选一种：

   **方式 A：命令行（推荐）** —— 在 `learn` 文件夹里执行：

   ```bash
   tcb hosting deploy . / -e 你的envId --ignore "cloudfunctions/**,cloudbaserc.json,*.md,node_modules/**,.git/**"
   ```
   `--ignore` 用来排除云函数代码和说明文档，它们不需要放到网站上。上传后可用 `tcb hosting list -e 你的envId` 查看文件列表，确认里面**没有** `cloudfunctions` 文件夹（如有，可用 `tcb hosting delete cloudfunctions --dir -e 你的envId` 删掉）。

   **方式 B：控制台网页上传** —— 在「静态网站托管 → 文件管理」里，上传 `index.html`、`kana.html` 等所有 `.html` 文件，以及 `css`、`js` 文件夹（还有以后新增的图片文件夹）。**不要**上传 `cloudfunctions`、`cloudbaserc.json` 和 `.md` 文件。

## 第 10 步：用默认域名测试

在「静态网站托管」页面能看到一个**默认域名**（形如 `xxxx.tcloudbaseapp.com`）。用手机和电脑分别打开，检查：

- [ ] 页面正常显示，假名练习可用
- [ ] 用自己的邮箱获取验证码 → 收到邮件 → 输入后登录成功，昵称正确
- [ ] 做几道题，换一台设备登录同一邮箱，进度能同步
- [ ] 排行榜能看到自己（需要本周有经验值）
- [ ] 退出登录后提交一条咨询 → 提示成功 → 你的邮箱收到通知 → 控制台 `inquiries` 集合里有这条记录
- [ ] 1 小时内连续提交 4 次，第 4 次应提示"提交太频繁"

> 默认域名一般仅适合测试（可能有访问限制或提示），正式对外宣传请绑定自己的域名。

## 第 11 步：ICP 备案 + 绑定自定义域名

在中国大陆的服务器上用自己的域名，**必须先完成 ICP 备案**。

1. 买域名（腾讯云 / 其他注册商均可），完成域名实名认证。
2. 备案类型：你的网站有课程咨询、口译接单等经营内容，请以**个体工商户**主体办理**经营性**相关备案。哪些情况还需要额外许可（如 ICP 经营许可证），以当地管理局和腾讯云备案页的最新要求为准，有疑问可咨询腾讯云备案客服。
3. 在腾讯云「ICP 备案」控制台提交资料，等待审核（时间以官方通知为准）。
4. 备案通过后：**静态网站托管 → 配置信息 / 域名管理 → 添加自定义域名**，按提示到域名解析处添加 CNAME 记录，并申请/上传 HTTPS 证书（控制台一般提供免费证书申请入口，以控制台为准）。
5. 回到第 4 步，把新域名加进**安全域名**。
6. 备案号要显示在网页底部并链接到 <https://beian.miit.gov.cn>（让做前端的同学或 AI 帮你加上）。

## 第 12 步：迁移与备份

- **数据库备份**：文档型数据库里每个集合都可以「导出」为 JSON/CSV，建议每月导出一次 `profiles`、`progress`、`inquiries` 保存在自己电脑上。控制台可能也提供自动备份/回档功能，以控制台为准。
- **网站文件**：本地这个 `learn` 文件夹就是完整源文件，建议另存一份到网盘。
- **迁移到新环境**：新建环境 → 重复第 3～9 步 → 把导出的 JSON 用「导入」功能导入对应集合。注意：用户的登录账号在"身份认证"里，**不随数据库导出**，迁移后用户需要用同一邮箱重新登录（新环境 uid 会变，旧进度需要手动对照处理）。
- **注销账号**：用户在网站上点"注销"后，会删除他的昵称和进度数据；登录身份本身（邮箱账号）需要你在 **身份认证 → 用户管理** 里手动删除（验证码登录的账号没有密码，SDK 不允许网页端自删）。咨询记录作为业务往来保留，用户要求删除时请在 `inquiries` 集合手动删除。

## 常见问题

**Q1：网页一直显示"离线模式"？**
检查 `js/config.js` 的 `envId` 是否填写正确、是否已上传最新版；浏览器按 F12 看"控制台（Console）"里有没有 `[BreezeAPI]` 开头的提示。也可能是网络无法访问 `static.cloudbase.net`（SDK 下载地址）。

**Q2：收不到登录验证码？**
先看垃圾箱；确认第 3 步"邮箱验证码"已开启且配置了发件方式；同一邮箱 60 秒内只能获取一次。

**Q3：登录、排行榜报错，但页面能打开？**
多数是**安全域名**没加（第 4 步），或云函数没部署成功（控制台 → 云函数，看 3 个函数是否都在、日志有没有报错）。

**Q4：咨询提交成功但没收到邮件？**
检查 `inquiry` 函数的环境变量三项是否齐全、授权码是否过期/被停用；控制台查看 `inquiry` 函数日志，若有 `mail send failed: EAUTH`，基本就是授权码不对。

**Q5：未登录访客提交咨询提示"暂时无法提交"？**
第 3 步的**匿名登录**没有打开。

**Q6：排行榜看不到自己？**
排行榜只显示本周（ISO 周，周一开始）有经验值、且设置了昵称的用户；登录后做题并同步一次即可。

**Q7：经验值同步后比本地少？**
为了防刷分，云端每次同步最多增加 500 经验。网页会保留本地的较大值，之后每次同步会逐步追平。

**Q8：要花多少钱？**
云开发、静态托管流量、云函数调用、域名、证书都可能计费，**价格以腾讯云控制台和官网最新说明为准**。建议在「费用中心」设置**余额/消费预警**，避免意外扣费。

**Q9：授权码、密码可以发给别人帮忙部署吗？**
不可以。需要别人协助时，可在腾讯云「访问管理（CAM）」里给协助者建子账号并只授予必要权限，用完删除。

## 朗读音频

`audio/v/` 里是用 VOICEVOX 预先合成的朗读音频（单词与例句 春日部つむぎ；旁白 冥鳴ひまり、男声 玄野武宏、女声 四国めたん；页脚已按规约标注）。新合成的音频要先用 `_工具/normalize_audio.py` 统一音量再放进 audio/v。
`audio/v/index.js`（句子）和 `audio/v/index-vocab.js`（单词、例句）列出已有的音频；没有录音的句子会自动改用浏览器朗读。
以后改了题目或例句，用「_工具」文件夹里的脚本补合成新句子即可。

## 报告问题（用户反馈 bug）

- 每个页面页脚、手机 ☰ 菜单里都有「报告问题」，点开是一个弹出表单：问题类型、所在页面（自动填好）、描述、联系方式（选填）。
- 提交时会自动附上页面地址、浏览器和窗口大小，以及最近的脚本报错，方便定位。
- 走的是和咨询表单同一个云函数 inquiry：邮件标题显示为「新课程咨询」，「意向课程」一栏写着「报告问题」，正文开头是【报告问题：类型】。没留联系方式的，联系方式显示「未留联系方式」。
