# 五十音发音音频

把每个音保存成 `文件名.mp3` 放在这个文件夹里（例如 `ka.mp3`、`shi.mp3`、`kya.mp3`）。
文件名和要朗读的假名见同目录的 `清单-文件名与假名.tsv`。

- 平假名和片假名读音相同，共用一个文件。
- `o2.mp3` 是「を」，`di.mp3`/`du.mp3` 是「ぢ」「づ」。
- 网站会自动优先播放这里的音频；缺少的音会改用浏览器朗读。
- 用 VoiceStudio 生成时，请使用允许商用的模型（例如 Qwen3-TTS，Apache-2.0），
  并在 `js/app.js` 顶部的 `voiceCredit` 里写明声源。不要使用 OmniVoice（CC-BY-NC，禁止商用）
  或克隆自他人/游戏角色的声音。

- 2026-10-19：原版音量偏小（峰值约 -18 dB），已统一放大到 -1 dB 左右，并做了轻度压缩和中高频提升，听起来更有力。放大前的版本备份在项目根目录「_备份/kana-原音量-20261019」，这个备份不用上传。
